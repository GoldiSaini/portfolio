# Project Context

The objective is to create one of the best Quality Engineering portfolios available.

This project is intentionally being developed as though it were a production SaaS application.

The emphasis is on:

- clean architecture
- reusable components
- engineering documentation
- accessibility
- SEO
- performance
- developer experience

The codebase should be understandable by another senior engineer.

The repository itself should demonstrate engineering maturity.

The owner is learning React while building this project.

All generated code should therefore remain simple, readable, and educational.
